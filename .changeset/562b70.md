Raise the Effect peer dependency floor from `>=4.0.0-beta.104` to `>=4.0.0-rc.112`. This is a breaking change for consumers resolving Effect below the new floor, which was necessary because semver sorts `rc` versions above `beta` versions. The previous range allowed applications to land on a version that sibling libraries (effect-auth, legation) cannot co-install with.
