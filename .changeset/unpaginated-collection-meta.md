`Assemble.unpaginatedCollection` takes an optional `meta`, the document's top-level metadata (a generation timestamp, a cache hint, an application-specific summary), and emits it as given. Without `meta` the document has no `meta` member. `Assemble.UnpaginatedCollectionOptions` and `Assemble.UnpaginatedCollectionDocument` gain a third type parameter, the type of the `meta` passed: no `meta` member when none was passed (the default), `meta` of that type when it was, and `meta` optional when the type admits `undefined`, so a caller can forward its own optional `meta` as is. The type is inferred `const`, as on `Handlers.collection`, so an object literal keeps its literal type; as there, a value typed by an `interface` with no index signature is rejected, so spread it (`{ ...stamp }`) or use a `type` alias. `meta.totalCount` is not special-cased: it is emitted verbatim, and with a `self` the document is then structurally assignable to `Assemble.CollectionDocument`. A collection whose total matters goes through `Assemble.collection`.
