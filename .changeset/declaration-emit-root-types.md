**A project that compiles with `declaration: true` can export an endpoint, group or client value without annotating it (#348).** Before, `export const plain = Endpoint.get(Article)` stopped declaration emit with TS4023 on `QuerySchema`, `Wire` and `effect`'s `NodeInspectSymbol` (plus `ReachableIncluded` with `include`, and `SparseResource` / `SparseUnion` with `fields`), under both TypeScript 7 and 6. The bundled `dist/index.d.ts` declares each namespace's members at module level and exports them only through a namespace alias, which declaration emit does not follow, so a type in a namespace the consumer's file did not import could not be named. Error classes were then inlined structurally, down to `effect`'s internal `NodeInspectSymbol` key.

- The package root now also exports, as types only, every type those inferred types mention that a consumer's file may not otherwise reach: `ApiErrorWire`, `BadRequest`, `Conflict`, `NotAcceptable`, `UnsupportedMediaType`, `AtomicOperations`, `AtomicResult`, `CollectionDocument`, `DataDocument`, `WireSchema`, `IncludedResources`, `ReachableIncluded`, `SparseResource`, `SparseUnion`, `IdempotencyHeaders`, `IdempotencyKeyInProgress`, `IdempotencyKeyMismatch`, `IdempotencyMiddleware`, `ContentNegotiation`, `CreatedLocation`, `SchemaErrors`, `BracketedKeys` and `QuerySchema`. Each is the same type as its namespaced name (`ApiError.Wire`, `Atomic.Operations`, `Middleware.ContentNegotiation`, …), which stays canonical. A name that would be ambiguous at the root carries its namespace as a prefix. These aliases are **type-only**: for runtime code, use the namespaced value (`ApiError.BadRequest`, `Middleware.ContentNegotiation`, `Document.CollectionDocument`, …). The root `CollectionDocument` and `DataDocument` are `Document.CollectionDocument` and `Document.DataDocument`, not the `Assemble` or `Client` document types. They exist for declaration emit only and will be deprecated once each module is published as a subpath export (#385).
- `Endpoint` now exports `ReachableIncluded` and `MembersReachableIncluded`, which were module-local, and re-exports `IncludedResources`, `SparseResource` and `SparseUnion`.
- Emitted declarations now name the middlewares (`import("@thomasfosterau/effect-jsonapi").ContentNegotiation`) where they used to inline them, so they are much smaller.

Not covered yet (#385): an endpoint over a resource defined in another file, exported from a module that does not import `Resource` itself, still needs that namespace in scope or an annotation. The README's Limitations section shows the workaround.
